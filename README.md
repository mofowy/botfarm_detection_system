# BotFarm Detection System

Прототип системи формування множини підозрілих акаунтів.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Що змінено

- Прибрано бокову вкладку з базою.
- SQL-база SQLite створюється автоматично під час запуску.
- Якщо база порожня, вона автоматично заповнюється тестовими підозрілими акаунтами: acc_1, acc_2, acc_4, acc_6.
- Під час аналізу CSV-файлу система сама перевіряє акаунти через SQL-базу.
