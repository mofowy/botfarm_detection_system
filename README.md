# BotFarm Detection System

Прототип системи для формування множини підозрілих акаунтів у соціальних мережах. Програма аналізує текстові повідомлення акаунтів, очищує дані, формує TF-IDF-ознаки та групує схожі профілі за допомогою алгоритму DBSCAN.

Додатково система використовує локальну SQLite-базу підозрілих акаунтів. Під час аналізу кожен акаунт перевіряється за цією базою, а результат відображається у таблиці разом із коротким поясненням.

## Основні можливості

- завантаження CSV-файлу з акаунтами та повідомленнями;
- очищення текстових даних;
- формування TF-IDF-ознак;
- кластеризація акаунтів за текстовою схожістю;
- перевірка акаунтів через SQL-базу;
- виведення результатів у вебінтерфейсі Streamlit;
- експорт результатів у CSV.

## Запуск програми

1. Встановити залежності:

```bash
pip install -r requirements.txt 
```

2. Запустити застосунок:

```bash
streamlit run app.py
```

3. Перейти по посиланню:

```bash
http://localhost:8501/
```

4. У браузері завантажити файл:

```bash
data/sample_accounts.csv
```

Натиснути “Запустити аналіз”.
Після цього система покаже таблицю результатів із кластерами, перевіркою через SQL-базу та поясненням для кожного акаунта.
